1. Request-Adaptive Execution for Efficient Hybrid LLM Inference
论文链接：https://arxiv.org/abs/2610.37432
发布时间：2026-10-27
类别：cs.DC
论文总结：混合注意力与 SSM 混排的模型一般固定层布局，所有请求走同一路径，对不同上下文依赖的请求并不划算。Morph 在每层内配对 Attention 与 SSM 层，用面向 prefill 的门控为每个请求选布局并固定到解码结束；运行时以选择性批处理兼容不同层选择，并用混合感知的上下文缓存保证前缀复用正确。六个数据集上吞吐最高提升 3.87 倍。
亮点：把"每个请求一套层布局"做成仍可批处理的运行时，混合模型的静态布局假设被打破。

二、KV Cache 复用相关学术论文
1. DCKV: Learned Transform Coding of the Prompt KV Cache in Hybrid Language Models
论文链接：https://arxiv.org/abs/2610.36950
发布时间：2026-10-27
类别：cs.LG; cs.AI
论文总结：混合模型只在少数全注意力层保留 KV cache，但这份 cache 仍随 prompt 增长，复用时要存储和搬运。DCKV 是首个端到端训练的可微 KV cache 编解码器：变换、量化器与熵模型以 prompt token 和已解码邻位为条件，与冻结的语言模型联合优化，同时压低码长与输出偏差。Qwen3.5-2B 上压缩超 55 倍仅掉 1.8 分，超 100 倍掉 3.6 分。
亮点：把 KV cache 当作码流来训练，压缩率与精度损失第一次可以显式折算。

三、推理 Infra 相关学术论文
1. To Keep or Not to Keep: Learning KV Cache Retention in Disaggregated LLM Serving Systems
论文链接：https://arxiv.org/abs/2610.28637
发布时间：2026-08-10（10 月公告）
类别：cs.LG; cs.DC，ACM SYSTOR 2026
代码：https://github.com/FastLM/KVLearn
论文总结：PD 分离把 KV 的计算与消费分到不同节点池，一次 miss 不再只是本地重算，还要跨网络搬运，准入一块缓存同样要付传输代价。KVLearn 用前缀复用预测器估计复用概率，再按重算、传输和存储成本折算成保留分数，并在线校准准入阈值。端到端 TTFT 较无缓存降 56%、较 LRU-Pool 降 38%，跨节点 KV 传输量降 53%。
亮点：把网络传输成本写进淘汰决策，分离式部署才不会继续沿用单机缓存假设。

五、Vibe Coding 的 Nice Practice
1. 让 agent 测自己的测试，别把全绿当成通过
来源链接：https://developer.vonage.com/en/blog/beyond-vibe-coding-best-practices-2026
时间：2026-07-07
问题描述：AI 写的测试很容易自证——把被测逻辑用 mock 复刻一遍，或断言宽到任何实现都能过，测试全绿却挡不住回归。vibe coding 里这种假绿灯比没有测试更危险，因为它让人误以为验证已经完成。
具体做法：先让 agent 写会失败的测试并确认失败原因正确，再改实现让它转红为绿；随后要求它"测自己的测试"，注入错误或改坏实现看断言是否真的报错；再让第二个模型做红队挑刺；涉及支付、权限、生命周期等路径，一律人工复核。
