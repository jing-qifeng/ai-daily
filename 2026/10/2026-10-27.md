论文总结: 论文发布于 9 月中旬。该工作用近似排队模型刻画 LLM 推理服务中 prefill 与 decode 的多路复用执行，以三个参数（单迭代基础开销、每 token 计算成本、每 token KV cache 访问成本）描述模型与加速器组合，进而预测 TTFT 与 ITL。在 H100 上，Llama-3.1-8B 的平均 ITL 预测误差约 5%。作者据此实现 SLO 驱动的自动扩缩控制器，在 OpenShift H100 集群上跟踪四倍负载爬升，127 个控制周期仅失误 1 次，精度与副本开销均优于不带时延目标的吞吐型分析器。

二、KV Cache 复用相关学术论文
1. SARIA: Persistence-Aware KV Caching with Coordinated DRAM-SSD Reload for LLM Agents
论文链接: https://arxiv.org/abs/2610.31169
发布时间: 2026-10-22
类别: cs.OS（操作系统）
论文总结: 面向多轮 LLM Agent 的 KV cache 持久化与复用问题，SARIA 联合管理 DRAM 与 SSD 两级缓存。写路径利用会话级时间局部性，结合驱逐与复用历史，仅把确有复用机会的 KV 块持久化到 SSD，避免全量写入带来的写放大与寿命损耗；读路径在 prefill 后将命中的 SSD 块提升进 DRAM，并由传输协调器调度 DRAM 与 SSD 共享 GPU 入口带宽。基于 LMCache MP 实现的评估显示，SSD 写入减少 57%-59%，平均 TTFT 较纯 DRAM 方案降低 42%-80%。
亮点: 用会话级复用历史决定哪些 KV 值得落盘，让 SSD 在 KV cache 体系里既省钱又不拖慢首 token。

1. InferSlice: A Reference Architecture for SLO-driven LLM Inference over a Telco Wide-Area Network
论文链接: https://arxiv.org/abs/2610.32638
发布时间: 2026-10-23
类别: cs.DC（分布式计算）
论文总结: 由 BT 联合布里斯托大学与 NVIDIA 提出，面向电信广域网上的 SLO 驱动 LLM 推理参考架构，整合网络切片、GPU 分区、弹性服务与可观测性，并在英国全国试验网 JOINER 上实测。结果显示：服务分层可形成明显的时延-吞吐区间；权重流式加载可缩短跨站点扩容时间；副本复制对放置位置不敏感但受内存约束；流水线并行能容忍近距与中距跨站跳数，而张量并行与 prefill/decode 分离一旦跨出单个子网就失效。
亮点: 给出广域推理的实测边界：P/D 分离和张量并行跨子网即失效，流水线并行与权重流式才是广域网上的可行解。

五、Vibe Coding Nice Practice
1. 第三次解释同一流程时，就写成 Skill
问题描述: 用 AI 编码时，同一个操作流程（如新增一条 webhook 路由的完整步骤）往往要反复口头解释，既拖慢节奏，又让 AGENTS.md 越堆越大，占用每次对话的上下文。
具体做法: 采用三次法则：第一次直接向 agent 解释怎么做；第二次发现自己在重复解释时保持警惕；第三次就把该流程沉淀成独立的 SKILL.md，agent 按需加载，AGENTS.md 保持精简，流程变更时只需改一处。参见 https://developer.vonage.com/en/blog/beyond-vibe-coding-best-practices-2026
